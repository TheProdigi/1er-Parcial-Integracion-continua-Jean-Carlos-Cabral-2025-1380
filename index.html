GitHub Actions
+ Surge.sh

Esta página web forma parte de una práctica de integración continua. El objetivo es crear una página HTML, subirla a GitHub y configurar GitHub Actions para realizar su despliegue automáticamente utilizando Surge.sh.

Ver el proceso

¿Cómo funciona?

El proceso conecta el desarrollo local con el despliegue automático.

1

Desarrollo

Se crea el archivo index.html y se trabaja desde un repositorio local de Git.

2

GitHub

El proyecto se sube a un repositorio de GitHub mediante un push.

3

GitHub Actions

El workflow detecta el cambio y ejecuta automáticamente las instrucciones configuradas.

4

Surge.sh

Finalmente, los archivos de la página son desplegados automáticamente en Surge.sh.

Tecnologías utilizadas

Herramientas utilizadas durante la práctica.

GitHub Actions

Servicio de automatización integrado en GitHub que permite ejecutar procesos automáticamente cuando ocurren eventos en el repositorio, como realizar un push a la rama principal.

Surge.sh

Plataforma utilizada para publicar páginas web estáticas de manera sencilla. En esta práctica se utiliza como destino final del despliegue.

Despliegue automático

El objetivo principal es reducir el trabajo manual durante la publicación de la página.
